## App Review Notes

Version 1.0.8 improves customer control without changing PepMod's educational,
non-prescriptive boundary:

- **Twice-weekly schedules:** Create or edit a twice-weekly item and select
  exactly two weekdays. Legacy schedules retain the Mon/Thu fallback.
- **Reminder recovery:** If notification permission is blocked, Protocol and
  Profile show a persistent recovery card that opens the system app settings.
- **Store-derived offer copy:** Trial and price details appear only when the
  installed storefront returns a matching offer and eligibility state.
- **Library and custom entries:** New neutral reference entries carry no preset
  dose. Custom compounds and blend vials remain entirely user-entered.
- **Unit converter:** During protocol creation, open the vial-to-draw converter,
  enter values, and apply the calculated syringe-unit amount to the item.
- **Weekly history:** Open the full-width weekly planner from Protocol to review
  taken, skipped, missed, and unlogged recent entries and backfill a past entry.
- **In-app language:** Open Profile > Language, select a supported language,
  and relaunch to confirm the selection persists.

App Review demo account:

PepMod remains an educational tracking and unit-conversion tool. It does not
recommend doses, protocols, or mixing plans. The ATT request remains on the
first visible app session before tracking-capable attribution starts; declining
tracking does not block app use.
