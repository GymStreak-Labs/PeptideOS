## App Store — What's New (en-US)

PepMod now speaks your language and makes protocol tracking easier.

- Use PepMod in German, Spanish, French, Italian, Japanese, Korean, and Portuguese.
- Review scheduled doses in the new weekly planner.
- See the last injection site used for each peptide before logging.
- Open vial math and unit conversion directly from Library.
- Save protocol notes and see upcoming phase changes.
- Reminders now refresh when your device language changes.

PepMod remains an educational tracking and unit-conversion tool. It does not
recommend doses or mixing plans.

## App Review Notes

Version 1.0.7 adds complete customer-facing localization and several tracking
improvements without changing PepMod's educational, non-prescriptive boundary:

- **Languages:** Change the device language to German, Spanish, French, Italian,
  Japanese, Korean, Portuguese, or Brazilian Portuguese and relaunch PepMod.
  User interface copy, bundled educational reference content, system permission
  rationale, dates, numbers, decimal input, purchase errors, and scheduled
  reminder copy follow the active locale.
- **Weekly planner:** Open Protocol and select the calendar action to review the
  current week. Navigate between weeks and select a day to see scheduled times,
  amounts, phase context, and washout state.
- **Last injection site:** Log a dose for a peptide with prior injection history.
  The sheet shows the most recent recorded site for that specific peptide and
  ignores skipped, pending, and unrelated peptide records.
- **Unit conversion:** Open Library and select **Unit converter**. Vial math and
  reconstitution tools remain unit-conversion workflows based only on values
  entered by the user.
- **Protocol context:** Open an active protocol to save protocol-level notes and
  view the next configured phase-change checkpoint.
- **Localized reminders:** Existing PepMod dose and protocol reminders are
  rebuilt with localized copy after a device-language change. Stable reminder
  identifiers are preserved and unrelated notification categories are not
  cancelled.
